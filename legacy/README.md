# legacy — архив, не поддерживается

Здесь лежат ранние версии индикатора. Они сохранены как исторический артефакт:
показывают, откуда выросли `MoneyForesight_v2.pine` и `MoneyForesight_v3.pine`.

**Рабочие скрипты проекта — в корне репозитория:**

| Файл | Что это |
|---|---|
| `MoneyForesight_v3.pine` | актуальный индикатор («зона-магнит») |
| `MoneyForesight_strategy.pine` | версия для тестера стратегий TradingView |
| `MoneyForesight_v2.pine` | предыдущая версия индикатора, ещё поддерживается |
| `backtest.py` | независимый бэктестер на Python |

Код в `legacy/` **не правится**. Дефекты ниже задокументированы намеренно и
оставлены как есть — это решение по итогам код-ревью
[2026-09-08](../docs/reviews/2026-09-08-code-review.md) (находки 20–23).

## MoneyForesight.pine — не компилируется

Ошибки компиляции, из-за которых файл не является собираемым исходником:

- строка 263: `array.show` — такого метода в Pine нет;
- строка 847: незакрытый вызов функции;
- строка 1107: обращение к неопределённому `srtate`.

## MoneyForesight_Optimized.pine — компилируется, но с дефектами

- **Флаги пробоя S/R не сбрасываются между барами.** `resistancebroken` и
  `supportbroken` объявлены через `var` и после первого же пробоя остаются
  истинными навсегда — алерты срабатывают на каждом последующем баре.
  В v2 и v3 это уже исправлено: там они обычные побарные булевы.
- **Направление Fibonacci выбирается тождественным условием.** Проверка
  восходящего свинга `low_price < high_price` и нисходящего `high_price > low_price`
  алгебраически совпадают, поэтому оба набора коррекций считаются для любой пары
  пивотов независимо от того, какой из них был раньше. Правильный признак —
  порядок баров свингов, как это уже сделано в коде отрисовки.
- **Индекс цвета не защищён на прогреве.** `os = ta.rsi(filt, filter_length) / 100`
  может быть `na`, и это значение сразу уходит в `array.get` — риск падения по
  недопустимому индексу. В v2 и v3 значение обёрнуто в `nz()`.
